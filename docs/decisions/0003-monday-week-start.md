# 0003. 월요일을 한 주의 시작으로

**날짜**: 2026-05-24
**상태**: 채택 (Accepted)
**관련 PRD**: `04-main-board.md` (주 시작)

## 컨텍스트

캘린더 한 주의 시작 요일을 결정. 한국은 전통적으로 일요일 시작 캘린더 (한국 공식 캘린더, 카카오톡 캘린더, iOS 한국 기본 등). 그러나 ISO 8601 표준 + 비즈니스/플래너 사용 시 월요일 시작이 일반적.

## 결정

**월요일 시작 (`weekStartsOn: 1` in date-fns)**. 헤더 순서: 월/화/수/목/금/토/일.

`Settings.weekStart = 'monday'` 고정값으로 저장. 미래에 사용자 선택 가능하게 확장 여지 남김.

## 이유

1. **일기 앱이지 사회적 캘린더가 아님** — 약속/일정 관리가 아닌 개인 기록 도구. ISO 표준이 적합.
2. **주말이 한 묶음** — 토요일/일요일이 그리드 우측에 함께 — "주말"로 시각적 묶음. 일요일 시작이면 토/일이 양 끝에 분리됨.
3. **플래너/노트 앱 컨벤션** — Notion, Linear, Todoist 등 productivity 앱 다수가 월요일 시작.
4. **개발 표준** — `date-fns` `startOfWeek` 기본값 `weekStartsOn: 0` (일요일), 명시적으로 `1` 지정 (의도 명확).

## 결과

- `MonthBoard.tsx`: `startOfWeek(date, { weekStartsOn: 1 })` + `endOfWeek(date, { weekStartsOn: 1 })`로 그리드 범위 계산.
- 헤더 라벨: `['월', '화', '수', '목', '금', '토', '일']`.
- 7×N 그리드, 첫째/마지막 주 다른 달 셀은 빈 placeholder.

## 대안

- **일요일 시작**: 한국 사회 관습. 그러나 토/일이 분리되어 "주말 묶음" 시각이 약함.
- **사용자 선택 가능**: MVP에는 과스코프. `weekStart`를 `'monday'`로 고정하되 향후 v1.1+ 확장 여지.

## 재검토 시점

v1.1 — 본인 사용 + 외부 피드백 후 한국 사용자가 헷갈려하면 옵션화 (Settings 화면에서 `'monday' | 'sunday'` 선택).

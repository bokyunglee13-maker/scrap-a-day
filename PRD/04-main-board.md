# 04. 메인 화면 — 월간 우표 보드

> 주 사용: **Phase 2**

---

## 레이아웃

- **상단 헤더**: `← 2026년 5월 →` (월/년 + 좌우 화살표)
- **7열 그리드**: 월/화/수/목/금/토/일 (**월요일 시작**)
- **각 셀**: 우표 또는 빈 우표 슬롯
- **하단**: `17/24 days` 같은 진행 상태 표시 (선택적)

---

## 우표 셀 상태

| 상태 | 표시 |
|---|---|
| **빈 우표 (과거/오늘)** | 톱니 테두리 + 흰 배경 + 날짜 + (오늘은) 빛나는 외곽선 |
| **채워진 우표** | 사진 + 톱니 테두리 + 날짜 + 감정 점 (선택 시) |
| **미래 날짜** | 흐릿한 빈 우표 (탭 시 부드러운 메시지) |
| **다른 달 날짜** | 표시 안 함 (첫 주/마지막 주는 빈 칸) |

---

## 인터랙션

- **빈 우표 탭**: 등록 화면으로 이동 (`/new?date=YYYY-MM-DD`)
- **채워진 우표 탭**: 상세 화면으로 이동 (`/stamp/YYYY-MM-DD`)
- **좌우 스와이프** (모바일): 월 이동
- **좌우 화살표 클릭** (데스크탑/모바일): 월 이동
- **미래 날짜 탭**: 토스트 "내일을 기다려요" (이동 X)

---

## 월 이동

- 좌우 화살표가 기본
- 모바일에서 좌우 스와이프 추가 (선택, 어려우면 v1.1로 미룸)
- 현재는 월 단위만. 특정 년/월 점프는 v1.1

---

## 주 시작

**월요일 고정**. `date-fns`의 `startOfWeek(date, { weekStartsOn: 1 })` 사용.

헤더 순서: 월/화/수/목/금/토/일

---

## 진행 상태 표시 (선택)

하단에 작게: `17 / 31 days`

이번 달 채운 우표 수 / 이번 달 총 일수 (오늘까지만, 또는 한 달 전체).

너무 부담스럽지 않게, 회색 작은 텍스트로.

---

## 메인 화면 상단 액션

- **설정 진입**: 우측 상단 아이콘 (`⚙` 또는 lucide `Settings`)
- **이미지 내보내기**: 다음 아이콘 (`Share` 또는 `Download`) — 한 달 시트 PNG로 (Phase 5에서 추가)

---

## 빈 캘린더 (첫 사용)

전체 우표가 비어있는 경우:
- 캘린더는 정상 표시
- 오늘 빈 우표에 "첫 우표를 붙여볼까요?" 안내
- 별도 온보딩 화면 없음 (텅 빈 캘린더로 자연스럽게 시작)

## 성공 지표 (MVP)

### 본인 사용 검증 (최소 1개월)
- 매일 우표 붙이기 — 부담감 없이?
- 한 달 끝나고 캘린더 보기 — 시각적 만족?
- 수정/삭제 시도해보기 — UX 흐름 자연스러운가?
- 백업 한 번 해보기 — 작동 확인
- 한 달 시트 이미지 내보내기 — 인스타에 올려보기

### 측정 방법 (관측 데이터 활용)
12-observability.md §10.3의 사용 측정 데이터 활용:
- **방문일 수**: 한 달에 며칠 열었는가
- **등록 성공률**: 등록 시도 대비 성공
- **에러 발생 빈도**: 어떤 에러가 자주 나는가

이 데이터를 보고 v1.1 우선순위 결정.

### 외부 공개 검토 조건
다음 세 가지가 충족되면 외부 공개 검토:
1. **체감 부담감 없음** — "오늘도 우표 붙여야 해" 같은 부담 없음
2. **시각적 만족** — 한 달 끝나고 캘린더를 보며 즐거움
3. **버그 없음** — Phase 5 동안 데이터 손실 0건

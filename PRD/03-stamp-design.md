# 03. 우표 디자인 시스템

> 주 사용: **Phase 1** (우표 컴포넌트 구현). Phase 2~5에서 참조.

---

## 4.1 공통 구조

모든 우표는 다음 공통 규격을 공유 (시트 통일성):

- **종횡비**: 3:4 (세로형)
- **톱니 테두리**: 우표 가장자리에 원형 천공 (perforation) 마스크
- **빈 우표도 같은 톱니 사용** (단, 빈 우표는 항상 미니멀 톱니로 고정)

> ⚠️ 3종 스타일 모두 외곽 크기와 종횡비가 **반드시 동일**해야 함. 그래야 한 시트에 섞여도 정렬됨.

---

## 4.2 3가지 스타일

사용자가 우표마다 자유롭게 선택. 기본값은 미니멀.

### 클래식 (Classic)
- **느낌**: 진한 레트로, 우체국 도장
- **테두리**: 큰 톱니 (반경 ~3.5)
- **안쪽 테두리**: 진한 색 2px
- **날짜 위치**: **우측 하단** (액면가 위치)
- **날짜 폰트**: serif, 큰 사이즈
- **추가 디테일**: 작은 "SCRAP·A·DAY" 워드마크 (선택적)

### 미니멀 (Minimal) — 기본값
- **느낌**: 파스텔 톤, 사진이 주인공
- **테두리**: 작고 촘촘한 톱니 (반경 ~2)
- **안쪽 테두리**: 미세한 흰 라인
- **날짜 위치**: **좌측 상단** (흰 칩 위에 숫자)
- **날짜 폰트**: serif, 중간 사이즈

### 폴라로이드 (Polaroid)
- **느낌**: 흰 테두리, 손글씨 캡션
- **테두리**: 톱니 없음 (직사각형) — 흰 프레임 + 캡션이 폴라로이드의 정체성
- **사진 영역**: 정사각형 (위/좌/우 8% 여백, 아래 큰 여백)
- **날짜 위치**: **좌측 상단** (흰 칩) + 하단 손글씨 캡션 옵션
- **캡션 폰트**: Caveat / 나눔손글씨

## 4.3 감정 표시

### 5가지 감정

| 감정 | 색 | hex |
|---|---|---|
| 기쁨 | 노랑 | `#FAC775` |
| 평온 | 연두 | `#C0DD97` |
| 차분 | 하늘 | `#B5D4F4` |
| 우울 | 라벤더 | `#CECBF6` |
| 설렘 | 핑크 | `#F4C0D1` |

### 표시 방식
- **위치**: 우측 하단 점 (반경 6px, 흰 외곽선 1.5px)
- **표시 ON/OFF**: 우표마다 사용자 선택 가능
- **OFF인 경우**: 감정 데이터는 저장되지만 우표 그리드에서 보이지 않음 (상세화면에서만 보임)

---

## 4.4 빈 우표 디자인

- 톱니 테두리 (**스타일과 무관하게 미니멀 톱니 사용**)
- 흰 배경 + 미세한 안쪽 점선
- 날짜 (회색, opacity 0.5)
- 작은 안내 텍스트 (예: "오늘, 한 장" — 후킹 문구 참조)

---

## 4.5 "오늘" 강조

빈 우표인 오늘:
- 외곽선이 **부드럽게 빛남** (CSS: box-shadow 또는 stroke 애니메이션)
- 색은 액센트 컬러 (예: 부드러운 골드 `#FAC775`)
- 너무 화려하지 않게, 정적인 글로우 효과

---

## 4.6 컴포넌트 인터페이스

모든 스타일 컴포넌트는 동일한 props 받기 (일관성 검증을 위해):

```typescript
interface StampProps {
  stamp: Stamp;             // 또는 EmptyStampProps for 빈 우표
  size?: 'sm' | 'md' | 'lg' | 'xl';
  showDate?: boolean;       // 기본 true
  showMood?: boolean;       // stamp.moodVisible 따름
  onClick?: () => void;
}
```

### 반응형 사이즈

```typescript
const stampSizes = {
  sm: 'w-12',   // 모바일 캘린더 셀
  md: 'w-20',   // 데스크탑 캘린더 셀
  lg: 'w-48',   // 상세 화면
  xl: 'w-72',   // 공유 이미지
};
```

### 날짜 위치 계산

```typescript
function getDatePosition(style: StampStyle): 'top-left' | 'bottom-right' {
  return style === 'classic' ? 'bottom-right' : 'top-left';
}
```

## 4.7 톱니 마스크 구현

`PerforationMask.tsx`로 재사용 가능한 SVG 마스크 제공:
- 클래식: 큰 톱니 (반경 3.5)
- 미니멀: 작은 톱니 (반경 2)
- 폴라로이드: 톱니 없음

마스크는 SVG `<mask>` 엘리먼트로 구현. 코드 중복 줄이려고 톱니 좌표는 `lib/perforation.ts`에서 계산.

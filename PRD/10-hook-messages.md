# 10. 후킹 문구 사전

> 주 사용: **Phase 2** (빈 우표 안내), **Phase 3** (placeholder), **Phase 5** (시스템 메시지)

---

## 5.1 등록 화면 placeholder / 빈 우표 안내

| 상황 | 문구 |
|---|---|
| **기본 (낮)** | "오늘, 한 장" |
| **저녁 (18:00-22:00)** | "오늘은 어떤 하루였어요?" |
| **밤 (22:00 이후)** | "오늘이 가기 전에" |
| **연속 3일 빈칸** | "괜찮아요, 천천히 채워도 돼요" |
| **연속 7일 빈칸** | "오랜만이에요" |
| **월 마지막 날** | "이 달의 마지막 한 칸" |
| **첫 사용 (전체 빈 캘린더)** | "첫 우표를 붙여볼까요?" |
| **과거 날짜 (3일 이상 전)** | "지난 날을 떠올려볼까요?" |
| **미래 날짜 탭** | "내일을 기다려요" |

### 선택 우선순위
1. 첫 사용
2. 미래 날짜
3. 월 마지막 날
4. 연속 빈칸 7일+
5. 연속 빈칸 3일+
6. 시간대 (밤 → 저녁 → 기본)

`lib/hooks.ts`의 `getHookMessage()` 함수에 구현.

## 5.3 톤 가이드

### 성공 메시지
- 짧고 따뜻하게
- 명령형보다는 완료형 ("저장됐어요" > "저장됨")
- 이모지/느낌표 자제

### 실패 메시지
- 비난 X, 해결책 제시
- "X 못 합니다" → "X를 해주세요" 형태로
- 사용자 잘못 표현 자제

### 위험 작업 확인
- 다이얼로그로 명확하게
- "되돌릴 수 없어요" 명시
- 기본 버튼은 안전한 쪽 (취소가 default)

## 5.4 다국어 (참고)

MVP는 한국어만. v2.0에서 영어 추가 예정.

문구는 `lib/messages.ts`에 모아두면 추후 i18n 전환 쉬움:

```typescript
export const messages = {
  hook: {
    default: '오늘, 한 장',
    evening: '오늘은 어떤 하루였어요?',
    // ...
  },
  system: {
    saveSuccess: '우표를 붙였어요',
    // ...
  },
};
```

# 05. 등록 화면 — 우표 만들기

> 주 사용: **Phase 3**
> 🚨 **사진 변경 금지 정책 (06-stamp-detail.md §3.4)을 함께 숙지할 것**

---

## 라우팅

`/new?date=YYYY-MM-DD` — 쿼리 파라미터로 등록할 날짜 받음.

날짜 없이 진입하면 오늘 날짜로 기본 설정.

---

## 플로우 (3단계)

### 1. 사진 선택
- **두 가지 진입점을 명시 노출** (PRD §15 모바일 우선):
  - `카메라로 찍기` 버튼 → `<input type="file" capture="environment">` (즉시 카메라)
  - `사진 보관함에서 선택` 버튼 → `<input type="file">` (capture 없음, OS 갤러리)
  - 단일 input + `capture` 만으로는 iOS Safari가 항상 카메라만 띄움 → 두 input 분리 필수
- **사전 검증**:
  - 파일 크기 > 20MB → 안내 "더 작은 사진을 선택해주세요"
  - HEIC 등 미지원 포맷 → 안내 + JPEG/PNG 권장

### 2. 크롭
- `react-easy-crop` 라이브러리 사용
- **정사각형 (1:1) 크롭 영역**
- 드래그 / 핀치 줌 지원
- "확인" 버튼 → 크롭 데이터 저장 (원본 Blob은 그대로 유지)

### 3. 메타데이터 입력
- **메모**: 선택, 최대 100자, 글자수 카운터 표시 (`23/100`)
- **감정**: 선택, 5색 중 1개 (또는 미선택)
- **감정 표시 ON/OFF 토글**: 기본 ON
- **우표 스타일**: 클래식 / 미니멀 / 폴라로이드 (기본: 미니멀)

### 4. 저장
- "우표 붙이기" 버튼 → `createStamp` 호출 → 캘린더로 복귀
- 토스트: "우표를 붙였어요"
- 같은 날짜 이미 등록되어 있으면 에러 메시지 (11-failure-modes.md §9.2.2 참조)

---

## 미리보기

메타데이터 입력 화면에서 **실시간 우표 미리보기** 표시.

"이렇게 붙여질 거예요" 느낌. 사용자가 스타일/감정/메모 바꿀 때마다 즉시 반영.

---

## 디테일

- 메모 입력칸 placeholder: 후킹 문구 사용 (10-hook-messages.md 참조)
- 감정 미선택도 가능 (감정 없는 우표)
- 우표 스타일 기본값: 미니멀
- 등록 가능 날짜: **과거 자유, 미래 불가**
- **사진 없으면 등록 불가** (필수)

---

## 등록 시점 정책

- **과거 날짜**: 자유롭게 채울 수 있음
- **오늘**: 자유롭게 등록
- **미래 날짜**: 등록 불가, "내일을 기다려요" 메시지

기존에 등록된 날짜에 다시 등록 시도하면:
→ 에러 메시지 + 상세 화면으로 이동 안내 (수정하려면 그쪽으로)

---

## 등록 취소

- 헤더에 "취소" 버튼
- 작업 중 데이터 있으면 확인 다이얼로그: "작성 중인 내용이 사라져요"
- 작업 중 데이터 없으면 바로 캘린더로 복귀

---

## 화면별 실패 처리

상세는 `11-failure-modes.md` §9.2.2 참조. 핵심만:

- 저장 실패 → 폼 데이터 유지 + 재시도 버튼
- 같은 날짜 동시 등록 → 새로고침 안내
- 크롭 중 메모리 부족 → 사진 자동 다운스케일

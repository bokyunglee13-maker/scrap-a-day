# 13. 비기능 요구사항

> 주 사용: **Phase 1** (셋업 시 환경 결정), **Phase 5** (최종 검증)

---

## 성능

| 지표 | 목표 |
|---|---|
| 한 달 우표 30개 로드 | 2초 이내 |
| 사진 크롭 인터랙션 | 60fps |
| IndexedDB 쿼리 | 100ms 이내 |
| 메인 화면 첫 페인트 | 1.5초 이내 |
| PNG 내보내기 (우표 1장) | 3초 이내 |
| ZIP 백업 (30장) | 10초 이내 |

---

## 접근성

- **키보드 네비게이션**: Tab, Enter, Esc 모두 동작
- **스크린 리더 라벨**: 모든 우표 이미지에 alt 텍스트
  - 예: `"5월 24일 우표"` + 메모 있으면 첨부
- **색상 대비**: WCAG AA 준수
- **포커스 표시**: 명확한 outline 또는 ring
- **에러 메시지**: 색에 의존하지 말 것 (아이콘 + 텍스트 병행)

## 보안 / 프라이버시

- **로그인 없음** → 인증 관련 보안 이슈 없음
- **데이터 로컬 only** → 서버 전송 X, 누출 위험 최소
- **외부 분석 없음** → 사용자 추적 X
- **사진 메타데이터**: EXIF는 그대로 보존 (사용자가 사용. 추후 옵션화 가능)

## 한국어 처리

- 모든 사용자 노출 텍스트는 한국어
- 변수명/함수명은 영어
- 주석은 한/영 일관되게 (한 파일 내에서 섞지 말 것)

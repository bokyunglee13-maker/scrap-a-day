## 휴지통 (30일 보관)

### 정책
- 우표 삭제 시 즉시 영구삭제 X. `deletedAt = new Date()`로 표시 (소프트 삭제).
- 휴지통에 30일 보관 후 자동 영구 삭제.
- 사용자가 언제든 휴지통에서 즉시 비우기 가능.
- 휴지통에서 복원 시 해당 날짜로 복귀.

### 휴지통 화면 (`/settings/trash`)
- 삭제된 우표 목록 (`deletedAt IS NOT NULL`)
- 각 항목 표시: 미니 우표 + 날짜 + 삭제일 + "X일 후 영구 삭제"
- 각 항목 액션: `복원` / `영구 삭제`
- 상단 안내: "30일이 지나면 자동으로 영구 삭제됩니다."
- "휴지통 비우기" 버튼 + 확인 다이얼로그

### 복원 시 충돌
같은 날짜에 새 우표가 이미 등록된 경우:
→ "이미 등록된 날짜입니다. 새 우표를 삭제 후 복원하세요" 메시지

### 자동 정리
앱 로드 시 한 번 실행:
```typescript
export async function cleanExpiredTrash() {
  const thirtyDaysAgo = subDays(new Date(), 30);
  await db.stamps
    .where('deletedAt')
    .below(thirtyDaysAgo)
    .delete();
}
```

## 백업 (내보내기)

### 설정 화면 두 가지 옵션

#### 1. JSON 내보내기
- 메타데이터 (메모, 감정, 스타일, 날짜) 전체
- 파일명: `scrap-a-day-2026-05-24.json`
- v1.1에서 "가져오기"로 복원 가능 (현재 MVP는 내보내기만)

#### 2. 사진 ZIP
- 사진 파일들 묶음
- 파일명: `scrap-a-day-photos-2026-05-24.zip`
- 내부 파일명: `2026-05-01.jpg`, `2026-05-02.jpg`, ...

### 백업 실패 처리

상세는 `11-failure-modes.md` §9.2.4 참조. 핵심만:

- ZIP 생성 중 실패 → 부분 ZIP이라도 다운로드
- 메모리 부족 시 → 월별 분할 ZIP
- 진행 상태 표시 (사진 100MB+ 가능)

## 한 달 시트 PNG 내보내기

- 메인 화면 상단에 "내보내기" 아이콘
- 현재 보는 월 전체를 한 장의 PNG로 변환
- `html-to-image` 사용, `pixelRatio: 2~3`
- 다운로드 또는 Web Share API로 시스템 공유시트 호출

## 월말 회고 (간단)

### MVP 범위
메인 화면 하단 또는 별도 카드:
- 이번 달 채운 날 수 (`17/31일`)
- 감정 분포 (작은 색 막대 또는 도넛)
- "가장 많은 감정: 평온"

상세 회고는 **v1.1로 미룸**.

### 사용 통계 (관측 활용)
12-observability.md §10.3의 사용 측정 데이터를 회고에 표시:
- 이번 달 방문일 수
- 등록 성공률
- 최근 7일 활동
